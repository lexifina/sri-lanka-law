# 60D. Unlawful pretence to be assistant.
[ 29,30 of 1987]
(1) No person, not being a registered para-medical assistant, shall use any name , title or description implying that A para-medical he is registered under this Ordinance as a registered para-medical assistant.
(2) No person whose name is included in any part of the register of para-medical assistants shall use any name, title or description or otherwise do any act of any kind, implying that the name of such person is included in some other part of that register in which it is not in fact so included.
