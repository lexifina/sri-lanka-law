# 66. Change of security.
[ 12, 30 of 1955]
The appropriate authority may, in lieu of the whole or any part of any security which that authority has already accepted for any loan, accept new security if the new security if the new security, either alone or together with any portion of the original security which is to remain, is sufficient for a new loan of an amount equal to the total of the principal and interest still outstanding on account of the original loan.
